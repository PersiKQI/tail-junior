# Персонажи

Три отдельных PNG с прозрачностью:

| Персонаж | ID | Файл |
|---|---|---|
| Люми | lumi | [lumi.png](../lumi.png) |
| Искра | spark | [spark.png](spark.png) |
| Нова | nova | [nova.png](nova.png) |

Персонаж выбирается при знакомстве, сохраняется в профиле и может быть изменён на главной или в профиле. Выбор влияет только на оформление. Иллюстрации созданы с помощью генерации изображений; новые варианты Искры и Новы выдержаны в стиле исходного Люми.
