# Иллюстрации ТЭЙЛ

Метод: встроенный image_gen; не MidJourney и не API через CLI. Итоговые изображения скопированы в проект с сохранением прозрачности. Персонажи оригинальные; пользовательские референсы задавали композицию и настроение интерфейса.

- `lumi.png` — Люми, голубой объёмный персонаж с округлыми ушами, светлым животом и жёлтой звездой. Краткий бриф первоначальной генерации: дружелюбный 3D-помощник для приложения о первых финансовых решениях, прозрачный фон, без текста и логотипов. Здесь сохранён краткий бриф, не дословный первоначальный запрос.
- `headphones.png` — сиреневые объёмные наушники с голубыми бликами и маленькими звёздами. Краткий бриф первоначальной генерации: предмет личной цели в той же мягкой 3D-эстетике, прозрачный фон, без текста. Не дословный первоначальный запрос.
- `lumi-friends.png` — Люми с жёлтым и сиреневым персонажами, создан с `lumi.png` как референсом. Дословный финальный запрос приведён ниже.
- `icon.png` — программно отрисованный знак на градиенте по пользовательскому PDF; не генерация модели.
- `brand-reference.png` — рендер PDF пользователя, источник брендовых цветов и знака.

## Запрос для сцены с тремя персонажами

Use case: stylized-concept. Asset type: transparent cutout illustration for the Russian mobile app TEYL, a friendly money-learning app for ages 14–20. Reference image: the existing original blue character Lumi; preserve its blue rounded ears, large navy/white eyes, round pale-cyan belly and cheerful vinyl style. Create ONE cohesive trio illustration: Lumi in the middle, a smaller warm yellow rounded triangular character on the left looking curiously up, and a soft lavender rounded square character on the right with a relaxed smiling face. The trio is sitting side by side with a playful tilted pose, a few tiny lilac/pink/yellow four-point stars floating close around them. Blue character is tallest and waving. Expressive but clean sophisticated 3D toy render, subtly glossy, soft lighting, cyan and violet rim light. Wide horizontal composition, all three full characters entirely in frame, roughly equal spacing, no occlusion of faces, no background scenery, actual transparent alpha background, no floor, no text, no logos, no watermark. This is artwork, not a screenshot or interface mockup.
