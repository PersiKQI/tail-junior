# ТЭЙЛ junior

Мобильное приложение для изучения финансовой грамотности, накоплений и первых инвестиционных решений. React Native, Expo SDK 58, TypeScript; backend на Node.js и SQLite.

В приложении есть учебные истории, виртуальный портфель, цель накопления, месячный бюджет, журнал расходов, план недели и выбор персонажа. Учебный портфель использует вымышленные сценарии; банковское подключение и реальные сделки не выполняются.

## Требования

- Node.js **24 LTS, от 24.3** и npm. Если установлен nvm: `nvm install && nvm use`.
- Для телефона — Expo Go с поддержкой SDK 58.

## Быстрый запуск в браузере

Из корня репозитория:

```bash
npm ci
npm run dev
```

Открой **http://localhost:8081**. Команда запускает приложение и API; остановка — `Ctrl+C`.

Backend: `http://localhost:3001`. Проверка: `http://localhost:3001/api/health`.

Раздельный запуск в двух терминалах:

```bash
npm run api
```

```bash
npm run web
```

## Запуск на телефоне через Expo Go

Телефон и компьютер должны находиться в одной Wi-Fi-сети.

1. Установи зависимости: `npm ci`.
2. Скопируй настройки: `cp .env.example .env`.
3. Узнай локальный IP компьютера. На Mac обычно: `ipconfig getifaddr en0`.
4. В `.env` укажи свой IP вместо примера:

```dotenv
HOST=0.0.0.0
PORT=3001
EXPO_PUBLIC_API_URL=http://192.168.1.10:3001
DATABASE_PATH=./data/teyl.sqlite
```

5. В первом терминале запусти backend:

```bash
npm run api
```

6. Во втором терминале войди в тот же аккаунт, что и в Expo Go на iPhone, и запусти Expo:

```bash
npx expo login
npx expo start --go --lan --port 8081
```

7. Отсканируй QR-код камерой iPhone или сканером Expo Go на Android.

На телефоне `localhost` указывает на сам телефон, поэтому для API нужен IP компьютера. Если приложение не соединяется с сервером, открой на телефоне `http://<IP-компьютера>:3001/api/health` и проверь Wi-Fi и разрешение входящих соединений. После изменения `.env` перезапусти Expo. Если порт занят, останови предыдущий процесс или выбери другой порт; адрес API и значение `PORT` должны совпадать.

Туннель Expo сам по себе не открывает доступ к отдельному backend. Для доступа вне локальной сети нужен backend с HTTPS.

## Команды

```bash
npm run typecheck     # проверка TypeScript
npm test              # тесты расчётов, API, хранения и миграций
npm run build:web     # экспорт web в dist/
npm run build:native  # экспорт JS и ресурсов iOS/Android в dist-native/
```

Нативный экспорт не создаёт APK/IPA. Liquid Glass используется на поддерживаемых iOS; для остальных платформ предусмотрен упрощённый вариант оформления.

## Структура

```text
App.tsx        навигация и загрузка профиля
src/           экраны, компоненты и клиент API
server/        HTTP API и SQLite
shared/        общие типы
assets/        иллюстрации и персонажи
tests/         тесты
scripts/       совместный запуск приложения и API
```

База создаётся автоматически в `data/teyl.sqlite`. `.env`, локальные базы, зависимости и результаты сборки исключены из Git. Прогресс привязан к анонимному ключу на устройстве; после удаления ключа восстановление входа не предусмотрено. В мобильной версии ключ хранится в SecureStore.
