# ТЭЙЛ: границы MVP

Решение принято на основе глав 9–11 исследования и пользовательских референсов. Целевой первый пилот — 18–20 лет. 14–17 лет могут пройти только учебные сценарии; набор несовершеннолетних требует отдельного протокола. Проверяемый результат — пользователь строит посильный план накопления, корректирует его при изменении условий и решает новую задачу через неделю.

## Реализация

React Native + Expo + TypeScript, общий интерфейс iOS/Android/web. Node.js 24+ и SQLite: настоящий API с изолированными гостевыми сессиями, постоянным хранением плана, прогресса, ответов, самоотчётов и событий. Установка приложения в магазины и банковская интеграция не входят в локальную сборку.

## Путь

Первый вход → короткое знакомство без обязательной цели → домашний экран. Инвестиционный маршрут доступен сразу. Цель, бюджет и учебные примеры настраиваются по желанию. Маршрут накоплений: шесть заданий с фиксированным порядком и две симуляции (после третьего и шестого задания) → сохранение/корректировка плана → самостоятельная проверка в окне 144–216 часов с первого ответа. Статистика отражает только фактические ответы. Пополнение отмечается как самоотчёт, приложение не хранит и не переводит деньги.

## Визуальное решение

Градиент и белый знак взяты из PDF пользователя. Основные цвета: #2665FF, #42B5FA; основной текст #171D30; фон #F5F7FB. Большие блоки, радиусы 24–36, короткие заголовки, спокойные белые поверхности, крупная типографика. Персонаж Люми создан встроенным image_gen, прозрачный PNG хранится в assets/lumi.png. Плавная анимация отключается через системный Reduce Motion и настройку приложения. Из референсов используем иерархию, объём и воздух, не копируем чужие персонажи.

## Проверка

Автоматические проверки API: расчёты, порядок сценария, повторная отправка, разделение пользователей, сохранение после рестарта, контрольное окно, валидация. TypeScript, web и native bundles. Ручной проход всех основных экранов в браузере с мобильным размером; iOS/Android считаются проверенными на устройстве только после отдельного запуска на симуляторе/устройстве.

## Основания UX

- NN/g, Progressive Disclosure: дополнительные настройки плана открываются по необходимости. https://www.nngroup.com/articles/progressive-disclosure/
- NN/g, Aesthetic–Usability Effect: привлекательность не заменяет проверку выполнения задач. https://www.nngroup.com/articles/aesthetic-usability-effect/
- React Native accessibility: названия кнопок, состояния, масштабирование текста, reduced motion. https://reactnative.dev/docs/accessibility
- Основные визуальные ориентиры — пять изображений пользователя; дополнительные коллекции Awwwards используются только как контекст визуальной подачи.

## Ограничения интерпретации

70 из 100 — предварительная заинтересованность со слов команды, не доказанный спрос. MVP проверяет гипотезу; приложение не заявляет доказанную эффективность, не предлагает доходность, кредиты или реальные инвестиционные сделки. Учебный контент требует предметной проверки перед внешним пилотом. Анонимная сессия не восстанавливается на другом устройстве.

## Уточнение инвестиционного ядра · 31.10.2026

Накопления и инвестиции — две связанные учебные задачи. Сужение первого варианта до накоплений исправлено по обратной связи пользователя. Новый инвестиционный маршрут открывается сразу; исходные 8 шагов и окно D7 не смешиваются с шестью новыми историями. Сравнение четырёх инструментов сопровождается ссылками на первичные учебные материалы Банка России.

Лаборатория сравнивает один условный портфель при росте, снижении и раннем выходе. Цены заданы автором как учебные условия, не прогноз и не статистические вероятности. Комиссии учитываются расчётно, НКД исключён явно; [механизм НКД](https://www.tbank.ru/invest/help/educate/how-it-works/ways-to-invest/coupon-yield/) описан в словаре. Сервер пересчитывает итоги и проверяет ответы. Учебный результат не пополняет цель, не меняет бюджет и не даёт наград за прибыль. Первая попытка урока сохраняется неизменной, повтор — отдельно.

Бюджет получил отдельный журнал ручных расходов с мягкой отменой и восстановлением; цель — варианты темпа и интерактивный прогноз; практика — предварительные разборы, тренажёры и поиск по памяткам.
